# 니가타 료칸의 겨울 — HyperFrames 라인 드로잉 영상

30초, 1920×1080, 30fps. 눈 내리는 니가타 료칸과 노천탕을 먹선 라인 드로잉으로 그린 젠 스타일 영상.

- 완성본(무음): `renders/niigata-ryokan-silent.mp4`
- 장면: `compositions/ryokan.html`, 루트: `index.html`
- 음악 트랙(`assets/bgm/track.wav`)은 아직 없어 `data-hidden`으로 꺼 두었습니다. 파일을 넣고 `data-hidden`을 지우면 됩니다.

```bash
npx hyperframes preview
npx hyperframes render
```
